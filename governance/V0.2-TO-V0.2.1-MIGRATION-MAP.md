# v0.2 -> v0.2.1 Contract Migration Map

Status: Reconciliation Candidate

## Principle

v0.2.0 is frozen. No v0.2 schema is edited in place. v0.2.1 introduces canonical architecture names/semantics and adapters/mapping rules.

## Mapping

### `EvoIntelligenceFeedV010`

The old feed role is split by semantics:

- current/state query projection -> **Enterprise Context**
- durable fact/change/outcome observation -> **Enterprise Observation**

No automatic field-level conversion is assumed until schema adapters/golden fixtures prove it.

### `EvoOutcomeV010`

Operational outcome facts/projections -> **Enterprise Observation** subtype/profile.

EC interpretation, lesson or learned outcome remains EC intelligence and is not migrated into EVO observation semantics.

### `EvoCommandProposalV010`

Migrates conceptually to **Command Proposal**.

Canonical v1 separates proposal identity from Command idempotency and requires references to EVO-owned Command/input-schema versions.

### `EcExperienceProposalV010`

Migrates conceptually to **Experience Proposal**.

Canonical v1 adds modern Eidos Capability/Stability/Integrity/Decision Experience/admissibility semantics. Unsupported semantics fail closed or use declared deterministic fallback.

### `EidosActionRequestV010`

Migrates conceptually to Host-neutral **ActionRequest**.

Any EVO-specific target mapping moves into a separately certified **EVO Action Mapping Profile** / Host Adapter.

### No v0.2 equivalent

The following are new canonical boundaries/profiles:

- Operational Change Proposal
- Enterprise Simulation
- Shared Envelope semantic profiles

## Adapter Requirements

Every adapter documents:

- source contract/version
- target contract/version
- preserved fields/semantics
- transformed fields/semantics
- generated/defaulted fields and their authority
- unsupported semantics
- fail-closed conditions
- security/trust changes
- golden fixtures
- provider/consumer tests

## Rollback

Rollback means returning to the previous certified product+contract+adapter combination in the Compatibility Matrix. It never means modifying frozen v0.2 artifacts or reverting product internal architecture wholesale.
