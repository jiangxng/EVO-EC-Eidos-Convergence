# v0.2 Boundary

## Real upstream boundary already available

- EVO: public write = Command. AI does not bypass Human/Automation command path.
- Eidos: EC proposal 0.1.0 + experience context/composition validators.
- EC: knowledge/context/learning runtime used directly from the bundled v1.0.1 source.

## Candidate boundary introduced here

The convergence workspace defines the missing seams as candidate contracts. They can later be adopted into each owning repository without importing this workspace's private code.

## Why a Reference EVO Adapter exists

The APM shortage scenario needs an alternate-supplier procurement Command. That command is not present in the observed EVO 1.0.0-alpha.2 reference HTTP endpoints. The reference adapter allows the contract, authorization, idempotency, outcome and EC learning loop to be validated now without falsely claiming upstream functionality.
